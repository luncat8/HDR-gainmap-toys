HDR Canvas → Save — WebGPU HDR + plugin

This canvas is WebGPU rgba16float + toneMapping:'extended' — true HDR.
Plugin patches getContext('webgpu') and queue.submit to enable readback of getCurrentTexture().
Click HDR 📸 → HDR→Save to capture current HDR frame and save as Ultra HDR JPEG (SDR base + gain map derived from actual HDR ratio).
Plugin must be loaded before WebGPU context is created — note script order.
