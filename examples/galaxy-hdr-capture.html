Galaxy + HDR Plugin

Mini galaxy HDR demo (simplified). Original: github
To use with original: add
<script src="../hdr-gainmap-plugin.js"></script>
in <head> before WebGPU code.

Plugin adds HDR 📸 button. Click → HDR→Save to capture HDR frame as Ultra HDR JPEG.
Drag to rotate, scroll to zoom.
